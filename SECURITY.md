# Security Policy

## Supported versions

This repository is documentation only. The `main` branch is the only supported version.

## Reporting a vulnerability

If you discover a security issue in the guidance, scripts, or sample agent/prompt files in this repository, please report it privately via [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repo.

Please do **not** open a public issue for security-sensitive reports.

## Contribution & review policy

- Pull requests are welcome from anyone.
- All PRs must be reviewed and approved by a [CODEOWNER](.github/CODEOWNERS) before merge.
- Direct pushes to `main` are not permitted.
